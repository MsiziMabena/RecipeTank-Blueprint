Instructions of how to run and compile the software:

When you run the RECIPE TANK which is a recipe console application you will find a navigation panel with different options which  
will help you navigate through the application. First option is where you add the recipe you wish to save in the application. 
After you select the first option the application will prompt you to input the name of the recice which you want to save in the application. After 
 inputing the name of recipe, you will be prompted to enter the number of ingredients which will be used and their full details 
 which include the name of the ingredient, quantity, Unit of measurement, Calories and the food group of that ingredient. You
will then need to enter the number of steps required for your recipe and explain in full details in each step. Then all that data 
you inputted will be saved. Then the application will automatically take you back to the navigation panel. When you select option 2
the application will display the names you saved your recipes with. Then when you select option 3 it will show you options of the
 names of the recipes you stored then you select the option of your choice then the application will display all your recipe 
 details. If you want to scale your recipe you will select option 4 then input the scaling factor of your choice. Then to clear all
 the data you saved you select option 5 then the application will clear all the data and then print "All the data has been stored 
 successfully". Then to exit the application you select the last option which is option 6.
